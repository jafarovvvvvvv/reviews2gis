# Деплой Bedel на VPS

Цель: панель работает 24/7 без вашего ПК, доступна по HTTPS на домене и закрыта
паролем. Уведомления о негативе приходят, даже когда ваш ноутбук выключен.

## Что нужно

- VPS 2 vCPU / 4 GB RAM (Playwright + Chromium прожорлив), Ubuntu 22.04+.
- Домен (например `bedelreviews.kz`), A-запись → IP сервера.
- Установленные Docker и Docker Compose.

## Шаги

1. **Скопировать проект на сервер** (git clone вашего репозитория).
2. **Создать `.env`** рядом с `docker-compose.yml`:
   ```
   PANEL_PASSWORD=придумайте-длинный-пароль
   PANEL_HOSTS=bedelreviews.kz
   OPENAI_API_KEY=sk-...
   OPENAI_MODEL=gpt-5.4-mini
   TELEGRAM_BOT_TOKEN=...
   ```
   `PANEL_SECRET` можно не задавать — сгенерируется и сохранится в БД (сессии
   переживут перезапуск). Хотите фиксировать — добавьте `PANEL_SECRET=<64 hex>`.
3. **Указать домен** в `Caddyfile` (заменить `bedelreviews.kz`).
4. **Подготовить папку данных** (том БД монтируется файлом):
   ```
   mkdir -p data/backups data/output && touch data/monitor.db
   ```
5. **Запустить:** `docker compose up -d --build`
   Caddy сам выпустит TLS-сертификат. Откройте `https://ваш-домен` — будет форма входа.
6. **Привязать Telegram:** напишите боту `/start` (первый чат станет админом).

## Безопасность (важно)

- Панель **обязана** иметь `PANEL_PASSWORD` в интернете — без него вход открыт.
- `PANEL_HOSTS` ограничивает Host-заголовок только вашим доменом (анти-DNS-rebinding);
  POST с чужого Origin отклоняется (анти-CSRF). Это уже в коде (`guard`).
- Порт приложения наружу не публикуется — только Caddy (80/443).
- `.env`, `monitor.db`, `backups/` — никогда не коммитить (уже в `.gitignore`).

## Бэкап

Раз в сутки снимать БД и хранить 14 копий — cron на хосте:
```
0 4 * * * cd /path/to/bedel && docker compose exec -T app python backup.py --keep 14
```
Снимки лягут в `data/backups/` (том примонтирован). Восстановление — заменить
`data/monitor.db` нужным снимком и `docker compose restart app`.

## Обновление

```
git pull && docker compose up -d --build
```
БД и сессии сохраняются (том + `panel_secret` в БД).

## Проверка, что всё живо

- `https://домен/healthz` → `ok` (для аптайм-мониторинга, без пароля).
- Страница **«Состояние»** в панели: статусы карточек, ошибки подряд, лимиты.
- Если 2ГИС сломал парсер — при 3 ошибках подряд по компании придёт алерт
  «парсер не справляется» в админ-чат.

## Скорость проверок

В «Настройках»: интервал автопроверки (мин, ≥30) и лимит проверок/час. Для
платных клиентов — интервал 15–30 мин; лимит/час защищает от бана 2ГИС при
большом числе карточек (остаток переносится на следующий час).
