# Bedel (reviews2gis) — сводка проекта для консультации по раскрутке

> Обновлено: июль 2026. Назначение: самодостаточный контекст для ИИ/консультанта,
> который советует стратегию привлечения первых клиентов.

## Что это

**Bedel** (каз. «авторитет, репутация») — SaaS-сервис управления репутацией для
малого бизнеса Казахстана на базе отзывов **2ГИС**. Слоган: «вес вашей репутации».
Планируемый домен: bedelreviews.kz (ещё не куплен).

**Ядро ценности:** владелец бизнеса получает **Telegram-алерт о новом отзыве в день
публикации + 2 готовых AI-варианта ответа**, составленных по правилам модерации 2ГИС,
в тоне его бренда, на языке отзыва (русский/казахский — казахский это
KZ-дифференциатор). Автопубликации нет намеренно — против ToS 2ГИС, модель
полностью легальна.

**Вторая ступень ценности (удержание/апсейл):** аналитический отчёт «болей» — LLM
классифицирует до 300 отзывов по отраслевой таксономии (медицина/красота/общепит/авто),
считает вес и тренд каждой проблемы и выдаёт 3 конкретных действия на месяц.
Себестоимость отчёта — единицы тенге.

## Рынок (разведка июнь 2026)

- 2ГИС — 8,5 млн пользователей в KZ, карточка фактически решает, куда пойдёт клиент.
- SERM-агентства в Алматы стоят 100 000–300 000 ₸/мес — малому бизнесу недоступно.
  Bedel автоматизирует это за подписку.
- Подтверждённые боли: владельцы не умеют/боятся отвечать «по правилам» (2ГИС банит
  за оскорбления/рекламу в ответах); с апреля 2026 2ГИС показывает рекламу конкурентов
  на чужих карточках; «Отзывы Про» от 2ГИС RU-центричен и не даёт мгновенной реакции
  с готовым ответом.
- Пустые смежные ниши: Kaspi-мониторинг для ритейла (отзывы сгорают за 90 дней,
  рейтинг = позиция = деньги), white-label для SERM/SMM-агентств.
- Сбор отзывов (SMS/QR) исключён решением основателя. Накрутка — исключена,
  «чистое» позиционирование само по себе отстройка.

## Что уже есть (работает)

**Продукт:**
- Веб-панель (FastAPI + SQLite): добавляешь компанию ссылкой на карточку 2ГИС →
  мониторинг новых отзывов (скрапер на Playwright с антиботом), интервал настраивается,
  очередь с лимитами против бана.
- Telegram-бот: алерты с AI-ответами (копирование одним тапом, inline-кнопки
  «ещё вариант»), команды `/list /add /check /reply /report /digest`, роли
  админ/клиент, маршрутизация «компания → чат клиента».
- AI-ответы (OpenAI API): правила 2ГИС в промпте, тон бренда, ru/kk,
  ~600 токенов на отзыв.
- Отчёт болей: генерация из панели или команды бота, HTML→PDF, приходит файлом
  в Telegram.
- Кабинет клиента: read-only страница по неугадываемой ссылке (графики динамики
  рейтинга, отзывы, отчёты) — без логина, можно слать клиенту.
- Еженедельный дайджест и ежемесячный авто-отчёт (тумблеры).
- Демо-режим для встреч: фейковая клиника с историей рейтинга 3,8→4,6, поднимается
  за 10 секунд без скрапинга.
- Страница «Состояние», алерт «парсер умер», бэкапы, вход по паролю.
- Дизайн-система «карта города»: фирменные цвета/шрифты, рейтинг в пине-маркере.

**Инструменты продаж (лидген):**
- Парсер лидов: прогон по городу+категории 2ГИС → CSV лидов с приоритизацией +
  **пакет рассылки**: персональные сообщения-открывашки с реальными цифрами карточки
  («у вас 3 негативных отзыва без ответа, конкурент X обгоняет на 0.4 звезды»),
  ссылки wa.me с подставленным текстом, одностраничные HTML-аудиты для отправки
  после «да, скиньте».
- Продающий лендинг (герой с макетом Telegram-алерта, боли рынка KZ, шаги, тарифы,
  CTA на WhatsApp) — на `/lp`.
- Sales-playbook (`brand/sales-playbook.md`): сценарий 15-мин демо, шаблон КП,
  отработка возражений, тарифы.

**Инфраструктура:**
- Всё задеплоено на домашний сервер (Docker, автозапуск 24/7, авто-восстановление
  после отключения света), панель доступна в LAN, бот работает из любой сети
  (long-polling). Мониторинг сервера — Beszel.
- База перенесена: 10 компаний, 770 отзывов (тестовые данные основателя).

## Чего НЕТ (ключевое для советов по раскрутке)

1. **Ноль клиентов и ноль продаж.** Этап «валидация без кода» был пропущен решением
   основателя — продукт построен до первого клиента. Сейчас главная задача —
   первые продажи.
2. **Нет домена и внешнего доступа** — панель и кабинет клиента доступны только из
   домашней сети. План: купить домен при первом клиенте, открыть через Cloudflare
   Tunnel (технически всё готово, включая HTTPS).
3. **Нет юрлица/ИП, приёма платежей, тарифов в проде** — тарифы есть только на
   лендинге и в playbook.
4. **Контакт в лендинге — плейсхолдер** (wa.me не заполнен реальным номером).
5. **Нет ни одного канала привлечения**: нет Instagram-аккаунта продукта, нет
   контента, рассылки-открывашки ещё не отправлялись (пакет сгенерирован,
   но кампания не запускалась).
6. **Нет кейсов/отзывов о самом сервисе** — нечего показать как социальное
   доказательство (есть только демо-режим).
7. **Kaspi-мониторинг и white-label для агентств** — в роадмапе, не реализованы.
8. **Один основатель** (Эмиль), делает всё сам; бюджет на маркетинг минимальный.

## Экономика (ориентиры из роадмапа)

- Себестоимость обслуживания клиента — копейки: AI-ответ ~доли тенге, отчёт —
  единицы тенге, сервер домашний (бесплатный).
- Ценовой якорь рынка: агентства 100–300 тыс ₸/мес; час специалиста ~1900 ₸.
  Подписка Bedel может стоить в 5–10 раз дешевле агентства и всё равно иметь
  ~100% маржу.
- Аудит карточки как лид-магнит уже генерируется автоматически.

## Что нужно от консультанта

Стратегия получения **первых 1–10 платящих клиентов в Казахстане** (Алматы как
стартовый рынок): какие каналы (WhatsApp-рассылка по спарсенным лидам уже готова
технически, Instagram, обход ногами, партнёрство с SMM-агентствами), в каком
порядке, как упаковать оффер и цену, что сделать до первого касания (домен? ИП?
кейс на себе?), и как не убить время на нецелевые активности.
